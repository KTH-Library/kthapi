# Retrieve units in the KTH Directory for the first two levels (school, dep)

Retrieve units in the KTH Directory for the first two levels (school,
dep)

## Usage

``` r
kth_school_dep(cfg)
```

## Arguments

- cfg:

  a configuration setting for the KTH APIs including base URL etc, by
  default from config()

## Value

results records returned from the search

## Examples

``` r
if (FALSE) { # \dontrun{
kth_school_dep()
} # }
```
