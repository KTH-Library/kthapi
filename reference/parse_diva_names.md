# Parse all DiVA namestrings in DiVA publications

This function parses all DiVA namestrings in a set of DiVA publications.

## Usage

``` r
parse_diva_names(pubs = kth_diva_pubs())
```

## Arguments

- pubs:

  a data frame with diva publications, by default kth_diva_pubs()

## Value

data frame with results
