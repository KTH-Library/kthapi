# Run ldap search for kthid/orcid pairs

A LDAP search resulting in a list with three tibbles; for persons with
orcid data, persons with unit affiliation and persons with more than one
unit

## Usage

``` r
ug_orcid_kthid_unit()
```

## Value

list with slots for tibbles

## Examples

``` r
if (FALSE) { # \dontrun{
if(interactive()){
 ug_orcid_kthid_unit()
 }
} # }
```
