# Retrieve display name given kthid or accountname using the non-authed Profiles v 1.1 legacy API

Retrieve display name given kthid or accountname using the non-authed
Profiles v 1.1 legacy API

## Usage

``` r
kth_displayname_legacy(kthid, cfg = config())
```

## Arguments

- kthid:

  a string with the account name or KTH user id

- cfg:

  configuration setting for the KTH APIs including base URL etc, by
  default from config()
